# Web Development Assistant

## How-to topic
How to create websites using HTML, CSS, JavaScript, responsive design, and basic deployment.

## Run locally
1. Install Python 3.10+.
2. Open this project folder in Terminal/PowerShell.
3. Run: `pip install -r requirements.txt`
4. Run: `python app.py`
5. Open `http://127.0.0.1:5000`

## Features
- Responsive chatbot UI
- Flask backend
- SQLite chat history
- Step-by-step how-to prompts
- GitHub/Render-friendly structure
